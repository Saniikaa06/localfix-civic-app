# LocalFix

Report local problems (potholes, garbage, broken streetlights) with a photo and a map pin, and track them until they are fixed.

Live app: https://saniikaa06.github.io/localfix-civic-app/

## Features
- Citizens report a problem with type, description, photo and location
- Search any place, tap the map, or use GPS to set the location
- Authority dashboard with status counts and a colour-coded map
- Status flow: Reported, Assigned, In Progress, Resolved
- Upvotes so urgent issues rise to the top

## Tech
HTML, CSS, JavaScript, Leaflet.js, OpenStreetMap, Photon geocoding API, GitHub Pages
